## Landing card: a normal Apollo 11 landing

The short version of section 3. Details, branches and J-class changes are in the checklists.

```checklist
legend
band: BEFORE | Planner, then DSKY
- | TERMINAL | SWITCH TO 0. RUN plan.
- | PLANNER | Site, PLAN, SEND, close
- | TERMINAL | RUN dsky.
v: UPLINK ACTY lit, then V16 N33 E and V16 N81 E show the DOI
band: DOI | 3-2
- TIG-4:00 | DSKY | V37E 30E, PRO x4. V37E 40E
- | PRO | Turn. ENTR twice
- TIG-0:05 | V99 N40 FL | PRO
- | THROTTLE | MAN: raise to about 40 pct after 15 s
v: Cut-off, then PRO. Trim N85 to zero, PRO
band: BRAKING | 3-3
- NOW | DSKY | V37E 63E
- | PRO | Ship turns, warps to TIG-60 s
- TIG-0:05 | V99 N62 FL | PRO
v: V06 N63 from ignition
band: APPROACH | 3-4
v: V06 N64 FL
- | PRO | Permits redesignation
- | W / S, A / D | Move the aim point, if you want
band: LANDING | 3-5
- | P65 | Starts by itself. Settles to 3 ft/s down
- | H / N (or Shift / Ctrl) | P66, if you want to set the rate (SAS on)
v: CONTACT lamp, engine cuts off
- | PRO | Ends P68. Position stored
```

> CAUTION: P63 never stages. If you stage, cut the throttle first.
