Fonts used by the pilot's pack (make_pack.py embeds them, so the PDF looks the same on any PC):

Arimo-Regular/Bold.woff2  Arimo, static instances at weight 400 and 700 cut from the variable font (a variable font printed as Type 3 glyphs, which made the PDF slow to scroll). Apache License 2.0: Arimo-LICENSE.txt
CourierPrime-*.woff2    Courier Prime regular and bold (Google Fonts, Latin subset). SIL Open Font License 1.1: CourierPrime-OFL.txt
Zerlina.otf             Zerlina, the DSKY display digits, (c) 2019 Eugene Dorr. SIL Open Font License 1.1: Zerlina-OFL.txt
                        (digits, plus and minus only; used only for full register values such as +12345)
