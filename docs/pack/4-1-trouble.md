## 4.1 If something goes wrong

<!--table st-->
| Problem | Action |
|---|---|
| A key moves the wrong way | Flip the sign setting (2.4). |
| P63 refuses to start | See 2.2. Plan again if needed. |
| OPR ERR lit | [[RSET]]. |
| Anything else | The X in the DSKY window, then YES, ends the computer and gives you the controls. |
| Reporting a bug | Send `0:/lm/logs/rod.log`. Set `LOG` to TRUE, fly again, and send the other logs in that folder. |
