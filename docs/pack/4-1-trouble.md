## 4.1 If something goes wrong

<!--table st-->
| Problem | Action |
|---|---|
| A key moves the wrong way | Flip the sign setting (2.4). |
| P63 or P12 refuses to start | See 2.7. Plan again if needed. |
| The engine stopped after V37 in the ascent | V37 ends P12 and its burn. Nothing restarts it by itself: fly the rest by hand. |
| A rate-of-descent tap does nothing | Check SAS is on. Use H and N, or Shift and Ctrl: if one pair does not register on your keyboard, use the other. `ROD_KEYS` (2.4) can limit it to one pair. |
| OPR ERR lit | [[RSET]]. |
| Anything else | The X in the DSKY window, then YES, ends the computer and gives you the controls. |
| Reporting a bug | Send `0:/lm/logs/rod.log`. Set `LOG` to TRUE, fly again, and send the other logs in that folder. |
