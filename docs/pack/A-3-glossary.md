## A.3 Glossary

<!--table st-->
| Term | Meaning |
|---|---|
| AGC | Apollo Guidance Computer, which flew the Lunar Module |
| LM, CSM | Lunar Module, the lander. Command and service module, the mothership that stayed in orbit |
| Luminary | The AGC's LM software. Versions 099 (Apollo 11) and 210 (Apollo 15 to 17) are modelled |
| DSKY | Display and keyboard, the crew's panel for the AGC |
| Programme (P63) | A numbered mode of the computer. P00 is idle |
| Verb, noun | The two parts of a DSKY command: what to do, and which data |
| R1, R2, R3 | The three five-digit data lines of the display |
| ENTR, PRO, CLR, RSET, KEY REL | Enter, proceed, clear, reset, key release |
| OPR ERR | Operator error: a bad key entry |
| COMP ACTY | Computer activity: the computer is working |
| FL | Flashing |
| PAD | Pre-advisory data: the numbers Mission Control read to the crew |
| Uplink | Data sent from the ground; here, a file of key presses |
| `RLS`, `TLAND` | The landing site's position vector, and the landing time |
| TIG, TTG | Time of ignition, time to go |
| `DELVLVC` | A burn's delta-v in local vertical axes (Z down, Y opposite the orbit normal, X along the track) |
| VG | Velocity to be gained: what the burn still has to add |
| `ENG THR CONT` | Engine throttle switch: AUTO (computer) or MAN (pilot) |
| DOI | Descent orbit insertion, the burn that lowers the perilune to where the landing begins |
| PDI | Powered descent initiation, the descent engine ignition that starts the landing |
| LMDE | The LM's descent engine |
| Ullage | A small RCS push that settles the propellant before the engine lights |
| Redesignation | Moving the aim point the lander steers to, in P64 |
| ROD | Rate of descent. A ROD click is one tap of H, N, Shift or Ctrl in P66 |
| Window mode | `UP`: the ship turns so its window faces the site. `KEEP`: it keeps its roll |
| AUTO, ATT HOLD | The two attitude modes: the computer steers, or the crew holds attitude (SAS) |
| Clock zero | The mission time the AGC clock counts from |
| J-class | The later missions (15 to 17). Their software is Luminary 210 |
